# SimpleClientApp

This is a beginner-friendly C# console application that I created as part of my learning journey with .NET and C#.

The goal of this project is to practice:
- Creating classes
- Working with lists
- Accepting user input
- Understanding top-level statements in C#

## What This App Does

- Prompts the user to enter a client name and email
- Stores each client as an object
- Keeps adding clients until the user types `exit`
- Displays all entered clients at the end

This project helped me understand how objects and lists work together in C#.


## How to Run the App

Make sure you have the .NET SDK installed.

1. Open a terminal in the project folder
2. Run the following command:

```cmd
dotnet run
